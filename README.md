# SET

Приложение для организации съёмок: проекты, команда, тайминг, мудборд, образы, смета, бартер, учёт дохода, итоги для сторис.

Веб-приложение (PWA) без сборки: `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`.
Данные хранятся на устройстве (localStorage `set.v1`, фото — IndexedDB `set-media`).

При каждом выпуске поднимайте имя кэша в `sw.js`.
